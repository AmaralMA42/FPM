# Two scientific mediation paths — editorial illustrations

**Constructed examples of scientific reasoning**, not transcripts of real researchers, executed experiments or measured FPM effectiveness. Neither requires coding or statistical-physics knowledge. [Português](RESEARCH_PATHS.pt-BR.md).

## 1. Experienced education researcher, unfamiliar with AI workflows

**Researcher:** “I teach physics. I'd like to know whether a learning game actually helps students learn, but I don't know how to use AI to plan the study.”

**An unhelpful response:** immediately generate a questionnaire, program or statistical test and label it a complete protocol.

**Better mediation:**

- **Understand:** the objective is educational evidence, not agent setup. Distinguish conceptual learning, engagement, motivation and retention; ask about the outcome only if it changes the design.
- **Explain alternatives:** an exploratory pilot, intervention comparison or literature review answer different questions and carry different burdens of inference.
- **Design conditionally:** if comparing interventions, identify independent units (student, class or school), selection, pre/post measurement, controls, possible spillovers and relevant local ethical/institutional approval. Students within a class need not be independent replicates.
- **Next choice:** decide the primary learning outcome and what instruments or existing data are available before choosing the design.

**Limit:** no educational outcome was observed, no causal effect established and no human-subjects approval is implied.

## 2. Computational researcher reconciling campaigns

**Researcher:** “I have similar curves from two network simulation campaigns. Can I combine them to increase sample size, or should I run more points?”

**An unhelpful response:** merge CSV rows into one sample and recommend more simulation before checking the original designs.

**Better mediation:**

- **Recover:** identify the genuinely accessible raw files, parameters, programs, plots and graph identifiers; absence from this chat is not evidence of total loss.
- **Check comparability:** model rules, initial conditions, size, topology, estimand, normalization, stopping criteria and the graph/replica dependence hierarchy.
- **Separate uses:** displaying curves together, filling distinct measured coordinates and statistically pooling observations require different evidence and assumptions.
- **Specify validation:** exact replay recreates a historical execution; stochastic checks compare estimands under a compatible sampling design. Matching or mismatching seeds alone settle neither problem.
- **Next choice:** write a minimal compatibility table and identify the actual gap that might change the interpretation. Run additional simulations only if the gap remains material.

**Limit:** no dataset has been read or pooled, no statistical equivalence demonstrated and no new simulation performed.

## Shared lesson

The Companion helps researchers select scientifically useful next steps, while distinguishing **advice, actual execution, evidence and acceptance**. These vignettes are learning material, not an A/B benchmark or a claim of measured performance.
