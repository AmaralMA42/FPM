# FPM scientific method / Método científico do FPM

The **researcher's intention precedes tools and workflow**. A productive conversation can stop with an explanation, develop a researchable question or advance to analysis and experimentation; no universal sequence is required. The Companion aims to preserve the researcher's judgment while using AI to clarify alternatives, methods and evidence.

## A small shared vocabulary / Vocabulário mínimo

| State / Estado | Meaning / Significado |
|---|---|
| Idea / ideia | Curiosity or tentative mechanism / curiosidade ou mecanismo candidato |
| Proposed / proposto | Possible plan or prediction, not performed / possibilidade ainda não executada |
| Chosen / escolhido | Explicit researcher's choice / escolha humana |
| Executed / executado | Action actually performed with identifiable resources / ação realizada |
| Observed / observado | Output actually obtained / saída observada |
| Checked / verificado | Particular check against declared criterion / verificação delimitada |
| Interpreted / interpretado | Conclusion calibrated to evidence and scope / inferência proporcional |
| Accepted / aceito | Explicit approval in its stated scope / aceite humano competente |

## Transferable scientific judgment / Julgamento metodológico transferível

The following general lessons are adapted from **ratified internal FPM methodological practice**. They guide research when relevant; they are **not automatic gates** for every user question.

1. **Question before implementation.** Identify the phenomenon, researcher objective, competing explanations, assumptions, observables and the smallest discriminating result. An experiment is useful when it can change a scientific decision.
2. **Recover before recomputing.** Check what papers, datasets, programs, analyses and outputs actually exist and are accessible. Reanalysis often answers a question more efficiently than new simulation. An inaccessible file is a *gap*, not proof it was lost.
3. **Do not silently pool incomparable results.** Before statistical integration compare the model/dynamics, estimand, denominator, initialization, parameters, population, topology, sampling structure, dependence and censoring when pertinent. Showing two datasets side by side is not treating them as replicates.
4. **Separate replay from independent validation.** Replaying the same code, seeds and files tests traceability; comparing independent stochastic experiments tests agreement under a defined design and uncertainty. Neither guarantees scientific generality. Different seeds alone are not independent verification.
5. **Uncertainty has a sampling unit.** State whether an interval describes trajectories conditional on fixed graphs, across graphs, participants, sites or another population; respect correlations, selection and pairing. Zero recorded events and degenerate intervals do not establish zero underlying probability or uncertainty.
6. **Figures are evidence-bearing objects.** Identify the plot's scientific role and the link from source data through analysis to image; distinguish observed points, transformations, interpolations and selected examples. A representative illustration does not estimate population frequency; an image overlay is not full data regeneration.
7. **Revise the argument, not merely the prose.** Preserve established terminology, authorial intent, comparators, domains and the strength of claims. Prefer a focused diagnosis and local edit to gratuitous rewriting. Keep valuable negative results and unresolved discrepancies visible.
8. **Checks have different meanings.** File hashes, code running, analysis replay, figure recreation, scientific controls, semantic review, independent replication and human acceptance support different claims. Declare the scope of each check, avoid upgrading technical correctness into scientific validity, and avoid calling AI commentary an independent referee.
9. **Continuity without bureaucracy.** For long work, record the decision, evidence, limits and next action in a short transferable note. Recheck only the materially altered surface when a change is small; escalate when evidence or scientific interpretation changes.

**Context matters:** for a social-science intervention, the independent units may be students, groups or schools rather than simulation trajectories. For a qualitative inquiry, evidence may be interviews, documents or argumentation rather than numerical replicates. Apply the underlying epistemic distinction, not an irrelevant Monte Carlo checklist.

## Tools, limitations and evolution

AI tools are **replaceable means** and only usable when genuinely available. A Markdown starter cannot grant access to literature, Python, private files or memory. See the optional [tool guidance](../starter/TOOLS_AND_CHOICES.md), [evidence review](../starter/REVIEW.md) and [transfer note](../starter/NOTEBOOK.md).

This public guide is a **selected, accessible projection** of FPM's evolving methods: it does not contain the full internal governance, raw mission records or unapproved research data. Maintainers assess accepted methodological lessons for generality, evidentiary strength, permissions and relevance, then incorporate the useful delta in a public PR. Publication is deliberate, **not automatic synchronization**, and public suggestions are not silently promoted into internal canon.
