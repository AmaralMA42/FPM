# Limits, claims and verification / Limitações

**This version contains:** portable PT-BR/English START instructions, conditional guidance for scientific decisions and methods, optional critical-review and handoff notes, two editorial interdisciplinary research paths, and a small 2D Ising teaching example with stored exploratory outputs and basic source tests.

**Not demonstrated:** superiority over an ordinary AI chat, systematic usability with researchers, parity across AI services, autonomous discovery, persistent memory, self-updating tools, comprehensive scientific verification or precision estimation of Ising critical temperature. These are not inferred from clear instructions or the presence of a reproducible program.

Markdown instructions do **not** install an AI model, fetch unread papers, create data, or grant web, code execution, file, API or app permissions. Scientific claims must identify what was actually read, run and checked. Rules derived from computational research are applied only when pertinent to another field; scientific generality is not automatic.

**Ising:** quick-mode data are descriptive, temporally correlated finite-system samples. Three independent replicas per condition do not justify high-precision critical temperature inference; a basic exact-4×4 reference comparison does not establish full validation. `chi_abs` is a modified finite-size proxy rather than the strict zero-field susceptibility.
