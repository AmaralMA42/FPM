# Limits, claims and verification / Limitações

**What is in the starter package:** a portable conversation starter in PT-BR/EN, optional tool-choice and continuity notes, and an executable educational 2D Ising example with retained exploratory figures and basic source tests.

**What is not demonstrated:** improved performance relative to an unassisted AI chat; a validated study with researchers; reliable performance across AI services; automatic long-term memory; autonomous scientific discovery; exhaustive scientific verification; a precision estimate of Ising Tc; access to remote tools without the user's own environment.

A chat prompt does not install a language model or grant access to Python, full papers, data files, web search or third-party APIs. Claims of running experiments require real executed evidence. A user-facing research recommendation must distinguish assumptions from established knowledge.

**Ising scope:** the quick profile is qualitative/educational. Its chains are temporally correlated, finite systems do not have a nonanalytic transition, three independent replicates per cell are insufficient for precision Tc inference, and an elementary comparison with exact 4×4 enumeration does not establish global scientific correctness. `chi_abs` is explicitly a modified proxy.

**Privacy and publication:** do not paste confidential source text or unpublished data into public GitHub issues; when using any AI provider, check its privacy terms. Private FPM custody materials and the Quarantine Games scientific archive are **not bundled** with this starter. Before sharing unpublished data with any AI service, evaluate privacy and confidentiality requirements.
