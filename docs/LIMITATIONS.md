# Limits, claims and verification / Limitações

## What this public repository demonstrates today

The documentation states the intended research method, explains its boundaries and offers a **manual conversation example**. It does **not** currently distribute a working FPM Autoboot, HTML Navigator, simulation engine, scientific dataset or independent performance benchmark.

## What future releases must demonstrate

- Fresh sessions on different AI services can use the portable startup without relying on private context.
- Distributed code and HTML operate in declared environments with documented dependencies.
- Educational demonstrations are not confused with validated scientific conclusions.
- Packaging checksums, manifests and tests measure what they claim to measure.
- Authors' rights, third-party material, privacy and security are reviewed before distribution.

## Scientific and operational cautions

Text prompts cannot provision internet access, a Python environment, local files, a browser or computing resources. Generated references, equations, code and interpretations can be wrong. A coherent explanation is not a proof of a mechanism; a passed ZIP integrity check is not scientific replication.

FPM makes no guarantee of discovery, originality, publication, numerical correctness, safety of untrusted code or outcome quality.

**Researchers remain responsible for independent scrutiny, interpretation and publication decisions.**
