# Full Paper Machinist (FPM)

![Full Paper Machinist — official FPM visual identity](https://raw.githubusercontent.com/AmaralMA42/FPM/main/assets/brand/fpm-logo-horizontal.png)

**A bridge between your research ideas and AI tools.**

[Português](README.pt-BR.md) · [Get started](GET_STARTED.md) · [Conversation starter](starter/START.en.md) · [2D Ising example](examples/ising2d/README.md) · [Method](docs/METHOD.md) · [Limitations](docs/LIMITATIONS.md)

Scientific ideas rarely begin as fully specified research contracts. The **FPM Research Companion** helps researchers articulate what they want to understand, examine plausible questions and alternatives, choose suitable methods and tools, and progressively develop a feasible investigation. **Scientific decisions stay with the researcher.**

The intended contribution is a **conversational translation and guidance layer**, not a new autonomous scientific algorithm. In particular, it aims to help researchers unfamiliar with prompts, agents, and AI workflows. Its effectiveness has not been independently measured.

## Try it without installation

1. Open the [English conversation starter](starter/START.en.md). Use **Raw** to copy **the entire file** into a fresh chat with an AI assistant (or copy all text from the local ZIP).
2. Describe what you would like to investigate in your own words. For example: *“I want to explore whether collective behavior can show a phase transition, but I am not sure where to start.”*
3. Discuss the first suggested direction, ask for alternatives, or move directly to a technical plan. No forms or physics prerequisites.
4. If you want to continue later, ask for a compact transferable note using the optional [NOTEBOOK](starter/NOTEBOOK.md).

This is a portable set of Markdown instructions, **not an installed model or application**. Web access, coding, simulations, documents, and memories depend on the AI platform and its actual tools. A proposed experiment is not an executed one.

## A concrete scientific illustration

The optional [2D Ising lab](examples/ising2d/README.md) connects a question about magnetic order to models, observables, Monte Carlo code, and elementary checks. It includes exploratory stored outputs, **not a precision determination of the critical temperature**.

The separate [Quarantine Games on Networks research repository](https://github.com/AmaralMA42/quarantine_games_network) demonstrates a longer scientific project with code and preserved data. This repo does not copy its scientific archive or claim that the paper independently validates FPM's usefulness.

Experienced researchers can start directly from their technical problem without an introductory tutorial. [Method](docs/METHOD.md), [architecture](docs/ARCHITECTURE.md), [limitations](docs/LIMITATIONS.md) and [roadmap](docs/ROADMAP.md) explain the boundaries.
